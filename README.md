# SpaceInvaderTwo

Projet solo PyTorch pour le dossier du 4 juillet.

## Installation

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
```

## Lancement

```bash
python -m ufo_project.run_all
```

Le script téléchargera les relevés dans `data/` et écrira les résultats dans `outputs/`.
Ces dossiers sont ignorés par Git.
